# Cable Link — releases

Signed, notarized builds of **Cable Link**, which shares an iPhone's mobile data
with a Mac over the USB cable without Personal Hotspot.

- Website and downloads: https://cable-link.smallmarvel.com
- iPhone builds are distributed through TestFlight: https://testflight.apple.com/join/H5mZB757

Every release here is produced by an isolated signing service from a verified
build of the private source repository. Mac builds are universal (Apple silicon
and Intel), Developer ID signed and notarized; each asset ships with a SHA-256
checksum. The source code is not published.
